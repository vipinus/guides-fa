# ۰۴ · OpenVPN: پروفایل ‎.ovpn را دانلود، وارد و وصل کنید؛ روی روتر، NAS و Linux هم کار می‌کند

> نسخهٔ سایت (مفصل‌تر): https://www.leotun.com/fa/guides/openvpn-setup?utm_source=github&utm_content=client-04

OpenVPN پروتکل متن‌باز قدیمی و جاافتاده‌ای است و تقریباً همهٔ سیستم‌عامل‌ها، فریمورهای روتر و NASها کلاینتش را دارند. فایل‌های پروفایل LeoTun از قبل نام کاربری، رمز و اطلاعات رمزنگاری شما را دارند، پس همین که واردشان کنید می‌توانید وصل شوید. برای استفادهٔ روزمره روی گوشی و کامپیوتر، AnyConnect یا Hiddify کم‌زحمت‌ترند؛ ارزش OpenVPN در **جاهایی است که فقط OpenVPN را می‌پذیرند**: روترهای OpenWrt، NASهای سینولوژی / QNAP، سرورهای Linux و دستگاه‌های قدیمی‌تر.

## سه قدم

1. از جدول [صفحهٔ OpenVPN سایت](https://www.leotun.com/fa/openvpn?utm_source=github&utm_content=client-04) کلاینت سیستمتان را نصب کنید (همهٔ سیستم‌ها OpenVPN Connect رسمی را دارند؛ در Windows می‌توانید از OpenVPN GUI و در macOS از Tunnelblick هم استفاده کنید).
2. بعد از ورود، **روی پرچم یک منطقه بزنید** تا ‎.ovpn آن منطقه دانلود شود. برای هر منطقه یک فایل.
3. فایل را در کلاینت باز کنید و وصل شوید.

| سیستم | توضیح |
|---|---|
| Windows / macOS / اندروید / iOS | نام کاربری و رمز درون پروفایل است؛ وارد کنید و وصل شوید |
| Linux | تنظیمات VPN سیستم ← وارد کردن از فایل، و در اولین اتصال ایمیل و رمزتان در سایت را وارد کنید؛ در خط فرمان `openvpn --config file`؛ برای اجرا هنگام روشن شدن سیستم، فایل را در `/etc/openvpn/client/` بگذارید |
| روتر OpenWrt | luci-app-openvpn را نصب کنید، ‎.ovpn را بارگذاری و فعال کنید؛ اگر فریمور این سایت از پیش نصب است لازم نیست |
| NAS سینولوژی | Control Panel ← Network ← Network Interface ← Create ← VPN ← OpenVPN (‎.ovpn را وارد کنید)؛ برای اینکه ترافیک خروجی NAS از خط برود، «Use default gateway on remote network» (استفاده از دروازهٔ پیش‌فرض شبکهٔ راه دور) را تیک بزنید |
| NAS کیونپ (QNAP) | QVPN ← VPN Client ← Add ← OpenVPN، وارد کنید |

## کاربرانی که در چین هستند: اتصال مستقیم به سایت‌های چینی

بعد از اتصال، ترافیک سایت‌های چینی هم دور می‌زند. سایت یک «ابزار مسیر مستقیم داخل چین» می‌دهد: با دوبار کلیک اجرایش کنید تا IPهای چینی مستقیم وصل شوند و بقیه از خط بروند. هم با Cisco کار می‌کند و هم با OpenVPN. کاربرانی که بیرون از چین هستند نباید از آن استفاده کنند.

## اگر وصل نشد، به این ترتیب بررسی کنید

| کلیدواژهٔ لاگ / نشانه | علت | چه کنیم |
|---|---|---|
| AUTH_FAILED | نام کاربری یا رمز اشتباه است، یا حساب منقضی شده | وارد سایت شوید و تاریخ انقضا را ببینید؛ اگر رمز را عوض کرده‌اید، پروفایل را دوباره دانلود کنید |
| اول UDP زمانش تمام می‌شود، بعد با TCP وصل می‌شود | شبکهٔ فعلی UDP را محدود کرده و خودکار به TCP برگشته | قابل استفاده است ولی کندتر؛ اگر خیلی کند است، شبکه را عوض کنید یا به جایش از AnyConnect استفاده کنید |
| هم UDP و هم TCP خطای TLS handshake failed / key negotiation failed می‌دهند | مسیر شبکه تا سرور قطع است | منطقه یا شبکه را عوض کنید |
| خطا هنگام وارد کردن | کلاینت خیلی قدیمی است (پیش از OpenVPN 2.5) | کلاینت را به‌روز کنید |
| وسط اتصال ناگهان قطع می‌شود | حساب منقضی شده و سرور اتصالتان را قطع کرده | تمدید کنید و دوباره وصل شوید؛ پروفایل را لازم نیست عوض کنید |

## UDP یا TCP

هر دو موجودند و لازم نیست انتخاب کنید. UDP در پروفایل اول آمده، پس کلاینت اول UDP را امتحان می‌کند؛ اگر UDP محدود باشد یا وصل نشود، بعد از چند ثانیه خودکار به TCP می‌رود. UDP تأخیر کمتری دارد و سریع‌تر است؛ TCP فقط راه جایگزین است و در اتصال‌های بین‌کشوری به‌وضوح کندتر است. در شبکه‌هایی که UDP را همیشه محدود می‌کنند (برخی شبکه‌های دانشگاه و شرکت)، پیشنهاد می‌کنیم مستقیم از AnyConnect استفاده کنید.

> پروفایل‌هایی که پیش از ۱۵ سپتامبر ۲۰۲۶ دانلود شده‌اند فقط UDP دارند؛ اگر تغییر خودکار را می‌خواهید دوباره دانلود کنید.

## امنیت

فایل پروفایل نام کاربری و رمز شما را دارد و در حکم خود حساب است، پس آن را به کسی ندهید؛ اگر لو رفت، رمزتان را در سایت عوض کنید تا فایل قبلی بلافاصله از کار بیفتد. خود دست‌دهی (handshake) هم رمزنگاری‌شده است: بدون کلید داخل پروفایل حتی نمی‌شود دست‌دهی را شروع کرد و سرور برای اسکنرها دیده نمی‌شود.
