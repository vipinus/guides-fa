# ۰۱ · Cisco AnyConnect: نصب، اتصال و به‌روزرسانی روی همهٔ سیستم‌ها

> نسخهٔ سایت (مفصل‌تر): https://www.leotun.com/fa/guides/anyconnect-china?utm_source=github&utm_content=client-01

AnyConnect کلاینت VPN سازمانی شرکت Cisco است. نام رسمی‌اش حالا **Cisco Secure Client** است و همان‌طور کار می‌کند. نه فایل گواهی لازم دارید و نه وارد کردن پروفایل: آدرس، نام کاربری و رمزتان را وارد کنید و وصل شوید. برای اینکه در چین کار می‌کند یا نه و وقتی وصل نمی‌شود به چه چیزی بروید، [دسترسی به سرویس‌های خارجی از داخل چین، راهنمای ۰۲](https://github.com/vipinus/guides-zh-CN/blob/main/overseas-access/02-anyconnect-in-china.md) (به چینی) را ببینید.

## نصب

| سیستم | چه نصب کنیم | از کجا |
|---|---|---|
| Windows 10 و بالاتر | Cisco Secure Client 5.x | [صفحهٔ Cisco در سایت](https://www.leotun.com/fa/anyconnect?utm_source=github&utm_content=client-01) |
| Windows 7 / 8 | AnyConnect 4.9 (آخرین نسخه‌ای که از آن‌ها پشتیبانی می‌کند؛ دیگر به‌روز نمی‌شود) | همان بالا |
| macOS | Cisco Secure Client 5.x | همان بالا |
| iOS | Cisco Secure Client | App Store؛ اگر در فروشگاه نبود، OpenConnect متن‌باز را نصب کنید که همان پروتکل را دارد |
| اندروید | Cisco Secure Client | Google Play، یا فایل APK در صفحهٔ سایت |
| Linux | فایل نصب در صفحهٔ سایت، یا openconnect از مخزن توزیع خودتان | همان بالا |

در Windows، OpenConnect-GUI متن‌باز هم هست و همین حساب با آن کار می‌کند.

## اتصال در چهار قدم

1. کلاینت را باز کنید و آدرس سرور را در کادر آدرس وارد کنید. کاربران LeoTun می‌توانند در سایت **روی پرچم یک منطقه بزنند** تا آدرس آن منطقه کپی شود.
2. نام کاربری (ایمیلی که با آن ثبت‌نام کرده‌اید) و رمزتان را وارد کنید.
3. وقتی «Connected» (وصل شد) را دیدید، صفحه‌ای را که IP شما را نشان می‌دهد باز کنید تا مطمئن شوید خروجی در منطقهٔ انتخابی‌تان است.
4. برای عوض کردن منطقه از آدرس دیگری استفاده کنید. کلاینت آدرس‌هایی را که استفاده کرده‌اید به خاطر می‌سپارد، پس دفعهٔ بعد می‌توانید از فهرست کشویی انتخاب کنید.

## به‌روزرسانی

لازم نیست اول حذف کنید: نسخهٔ جدید را روی نسخهٔ قبلی نصب کنید و آدرس‌های ذخیره‌شده حفظ می‌شوند. روی گوشی از فروشگاه برنامه به‌روز کنید. بعد از ارتقای بزرگ سیستم‌عامل، اول کلاینت را به‌روز کنید و بعد سراغ عیب‌یابی اتصال بروید.

## پیام‌های رایج

| پیام | معنی |
|---|---|
| Login failed | نام کاربری یا رمز اشتباه است، یا حساب منقضی شده |
| Untrusted server certificate | به احتمال زیاد ساعت سیستم اشتباه است، یا شبکهٔ فعلی اتصال‌های رمزنگاری‌شده را رهگیری می‌کند؛ شبکهٔ دیگری را امتحان کنید |
| Connection attempt has failed | این آدرس موقتاً در دسترس نیست؛ منطقه را عوض کنید |
