# راهنمای کلاینت‌ها · نصب و راه‌اندازی

دستورالعمل قدم‌به‌قدم **نصب و اتصال** هر روش دسترسی: Cisco AnyConnect، ‏Hiddify، افزونهٔ پروکسی وب، OpenVPN و خصوصی (Tailscale)، به‌علاوهٔ اینکه وقتی iOS اجازهٔ نصب برنامه نمی‌دهد چه کنید، Telegram / Discord را چطور نصب کنید، چند دستگاه را چطور یک بار تنظیم کنید، و وقتی نرم‌افزاری مثل Dropbox پروکسی می‌خواهد چه کنید. برای انتخاب روش، [کدام روش اتصال به درد کدام موقعیت می‌خورد](../network/02-choose-your-connection-method.md) را ببینید؛ اگر نصب شده ولی وصل نمی‌شود، [عیب‌یابی](../troubleshooting/) را ببینید.
