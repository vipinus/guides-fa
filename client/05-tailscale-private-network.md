# ۰۵ · خصوصی (Tailscale): نصب، ورود به سرور کنترل این سایت، انتخاب خروجی

> نسخهٔ سایت (مفصل‌تر): https://www.leotun.com/fa/guides/tailscale-mesh?utm_source=github&utm_content=client-05

بخش «خصوصی» از Tailscale استفاده می‌کند (ابزار شبکه‌سازی‌ای که بر پایهٔ WireGuard ساخته شده). LeoTun سرور کنترل خودش را دارد و شما با **حسابتان در این سایت** وارد می‌شوید که ربطی به حساب رسمی Tailscale ندارد. یک بار وارد شوید و آنلاین می‌مانید؛ منطقهٔ خروجی را هر وقت بخواهید از منو عوض می‌کنید. برای اینکه چه فرقی با VPN دارد و به درد چه کسی می‌خورد، [راهنمای شبکه ۰۳](../network/03-private-network-vs-vpn.md) را ببینید.

## نصب

| سیستم | از کجا بگیرید |
|---|---|
| Windows / macOS / Linux / اندروید | بخش دانلود [صفحهٔ «خصوصی» در سایت](https://www.leotun.com/fa/mesh?utm_source=github&utm_content=client-05) (مستقیم از همین سایت، لازم نیست به سایت رسمی بروید) |
| آیفون / آیپد | App Store؛ Apple ID غیر از منطقهٔ چین لازم دارد ([کلاینت ۰۶](06-ios-app-store.md) را ببینید) |

## ورود

1. **اول از حساب رسمی خارج شوید** (اگر قبلاً وارد شده‌اید): روی گوشی، تصویر پروفایل ← Log Out؛ روی کامپیوتر، `tailscale logout` را اجرا کنید. تا کامل خارج نشده باشید، گزینه‌ای که در قدم بعد لازم است ظاهر نمی‌شود.
2. **ورود را به این سایت هدایت کنید**:
   - گوشی: در صفحهٔ خروج از حساب، «⋯» بالا سمت راست ← Use custom server (در بعضی نسخه‌ها Use an alternate server) را بزنید، آدرسی را که صفحهٔ «خصوصی» سایت داده وارد کنید و Log in را بزنید.
   - Windows / Linux: دستور `tailscale up --login-server=…` را از صفحهٔ سایت کپی کنید و در PowerShell / ترمینال اجرا کنید.
   - macOS: **روی Log in نزنید**. در پنجرهٔ Tailscale روی فلش ردیف حساب بزنید ← Account Settings… ← Accounts ← فلش کوچک کنار «Add Account…» ← Add Account Using Alternate Server، آدرس را بچسبانید و Add Account… را بزنید.
3. مرورگر خودکار صفحهٔ ورود این سایت را باز می‌کند؛ با حسابتان در این سایت تأیید کنید. وقتی به کلاینت برگردید، آنلاین است.

## انتخاب خروجی

- گوشی: منو ← Exit Node (گره خروجی)، یک منطقه انتخاب کنید؛ بلافاصله اعمال می‌شود.
- کامپیوتر: آیکون سینی سیستم / نوار منو ← زیرمنوی Exit Node؛ یا `tailscale set --exit-node=<region-name>` (با `tailscale exit-node list` می‌بینید چه گزینه‌هایی هست).
- برای اینکه خروجی نداشته باشید، None (هیچ‌کدام) را انتخاب کنید (در خط فرمان، بعد از علامت مساوی را خالی بگذارید). هر بار فقط از یک خروجی می‌شود استفاده کرد.

## انقضا و تعداد دستگاه‌ها

- اعتبار ورود هر دستگاه تابع تاریخ انقضای حساب است و ظرف چند دقیقه بعد از انقضا آفلاین می‌شود؛ بعد از تمدید فقط یک بار دیگر وارد شوید. نصب دوباره لازم نیست.
- تعداد دستگاه‌های آنلاین هم‌زمان به طرحتان بستگی دارد (شخصی ۲، خانوادگی ۴، سازمانی ۸) و این سهمیه با روش‌های دیگر مشترک است؛ وقتی از سقف طرحتان بیشتر شد، می‌توانید نوع حساب را موقتاً ارتقا دهید (زمان باقی‌مانده بر اساس قیمت با ارزش برابر تبدیل می‌شود) و بعد از تمام شدن کار برگردید.

## دو حالتی که روش دیگری مناسب‌تر است

- وقتی VPN دیگری روی همان دستگاه در حال اجراست (AnyConnect شرکت، نرم‌افزارهای شبکهٔ مش دیگر): سر DNS و مسیرها با هم دعوا می‌کنند. علتِ پیام حق پخش هنگام تماشای ویدیوی چینی و باز نشدن اینترانت شرکت همین است.
- در شبکهٔ دانشگاه / شرکت که UDP را محدود می‌کند: WireGuard روی UDP کار می‌کند، پس فقط از طریق رله‌های خود Tailscale (relay) می‌تواند عبور کند که خیلی کند است؛ به AnyConnect بروید.
