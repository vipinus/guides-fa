# دسترسی به چین از خارج · هر چیزی که IP چین لازم دارد

وقتی بیرون از چین هستید، بسیاری از سرویس‌های چینی چون IP شما در سرزمین اصلی چین نیست ردتان می‌کنند: ویدیو، موسیقی، خدمات دولتی، بانک، خرید بلیت، بازی. برای هر موقعیت یک مقاله، که روشن توضیح می‌دهد **چرا مسدود می‌شوید، چطور درستش کنید و چه دام‌های دیگری سر راه است**.

**پرخواننده‌ترین مقاله: [باز کردن سایت‌های ویدیوی چینی از خارج با روتر](../router/06-unlock-chinese-video-with-router.md)**؛ تلویزیون، ست‌تاپ‌باکس و همهٔ دستگاه‌های خانه یک بار تنظیم می‌شوند و همین که به وای‌فای وصل شوید می‌توانید iQIYI، Tencent Video و Yangshipin را تماشا کنید.
