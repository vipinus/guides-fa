# ۰۱ · کدام سرویس‌ها IP چین لازم دارند

فقط یک معیار هست: وقتی سرویس ببیند IP مبدأ شما در سرزمین اصلی چین نیست، ردتان می‌کند یا سرویس محدودتری به شما می‌دهد. جدول زیر بر اساس سخت‌گیری در مسدود کردن مرتب شده است.

| دسته | نمونه‌ها | بدون IP چین چه می‌شود | جز IP چه چیز دیگری بررسی می‌شود |
|---|---|---|---|
| ویدیو | iQIYI، Tencent Video، Youku، Mango TV، برخی سریال‌های انیمه در Bilibili | پیام می‌دهد فقط در سرزمین اصلی در دسترس است، یا فقط محتوای رایگان را می‌توانید ببینید | منطقهٔ فروشگاه برنامه، محل ثبت‌نام حساب |
| موسیقی | NetEase Cloud Music، QQ Music، Kugou | تعداد زیادی آهنگ خاکستری‌اند و پخش نمی‌شوند | هیچ |
| خدمات دولتی | پلتفرم ملی خدمات دولتی، سایت‌های خدمات دولتی استان‌ها، مالیات، بیمهٔ اجتماعی، صندوق مسکن | صفحه باز نمی‌شود، یا کد تأیید هیچ‌وقت نمی‌رسد | شمارهٔ تلفن، تشخیص چهره |
| آموزش | CHSI، سایت مدارک تحصیلی، سامانه‌های آموزشی دانشگاه‌ها | باز نمی‌شود، یا به‌شدت کند است | هیچ |
| سفر | ‏12306، سایت شرکت‌های هواپیمایی | باز نمی‌شود، پرداخت انجام نمی‌شود | شمارهٔ تلفن، پرداخت |
| مالی | بانکداری اینترنتی، بانکداری همراه، Alipay، WeChat Pay | ورود با کنترل ریسک متوقف می‌شود، انتقال انجام نمی‌شود | سیم‌کارت، اثر انگشت دستگاه، چهره |
| بازی | بازی‌های کامپیوتری و موبایلی با سرور چین | وارد می‌شوید ولی تأخیر زیاد است و قطع می‌شوید | احراز هویت با نام واقعی |
| زندگی روزمره | Meituan، Ele.me، DiDi، برخی امکانات Taobao | خطای موقعیت مکانی، سفارش ثبت نمی‌شود | موقعیت مکانی، شمارهٔ تلفن |
| پخش زنده | Douyin، Kuaishou، Douyu | در برخی منطقه‌ها قابل تماشا نیست | هیچ |

## یک تمایز مهم

**«IP چین لازم داشتن» و «شمارهٔ تلفن چینی لازم داشتن» دو چیز جدا هستند.** ویدیو و موسیقی فقط به IP نگاه می‌کنند و عوض کردن IP کافی است. خدمات دولتی، بانک و خرید بلیت جز IP از شما می‌خواهند کد تأیید پیامکی بگیرید و از تشخیص چهره رد شوید. IP مسئلهٔ «باز می‌شود یا نه» را حل می‌کند؛ تأییدهای بعدی به شمارهٔ تلفن چینی و مدارک هویتی خودتان بستگی دارد.

## راه‌های حل مسئلهٔ IP

ترافیک را اول به سروری در سرزمین اصلی چین بفرستید تا آن سرور به مقصد سر بزند. سه راه برای این کار هست: کلاینت، پروکسی وب یا روتر. برای انتخاب، [کدام روش اتصال به درد کدام موقعیت می‌خورد](../network/02-choose-your-connection-method.md) را در بخش همسایهٔ همین مخزن ببینید.
