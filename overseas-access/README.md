# دسترسی به سرویس‌های خارجی از داخل چین

در چین هستید و سرویس‌های خارجی‌ای که برای کار، برنامه‌نویسی، پژوهش، بازی و تماشای ویدیو لازم دارید باز نمی‌شوند یا به‌شدت کندند. هر مقاله یک موقعیت را پوشش می‌دهد و روشن می‌گوید **چه لازم دارید، چطور انتخاب کنید و دام‌ها کجاست**.

**برای کل خانواده یا کل دفتر**: [تفکیک ترافیک روتر](../router/03-router-split-routing.md) را ببینید. به‌طور پیش‌فرض فقط سایت‌های مسدود از خط می‌روند؛ سایت‌های چینی و سایت‌های خارجی‌ای که در چین بدون مشکل باز می‌شوند مستقیم وصل می‌شوند، و روی دستگاه‌ها هم چیزی نصب نمی‌شود.
